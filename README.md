# Mi portfolio personal

Este proyecto es un portfolio personal desarrollado durante el primer curso del ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM).

El objetivo es mostrar información personal, formación académica y los trabajos realizados durante el curso.

## Páginas del portfolio

- `index.html`: Página principal y presentación personal.
- `sobre-mi.html`: Información sobre mi trayectoria, aficiones y objetivos.
- `proyectos.html`: Página de proyectos.
- `cv.html`: Formación académica y competencias.
- `contacto.html`: Formulario de contacto.

## Tecnologías utilizadas

- HTML5
- Visual Studio Code
- Git
- GitHub
